# Еженедельная встреча — поисковая платформа

## Участники
Бэкенд, фронтенд и инфраструктурная команда.

## Обсуждение

Мы рассмотрели новый сервис индексации файлов. Apache Tika теперь извлекает
текст из вложений PDF, DOCX и XLSX в дополнение к обычным текстовым и markdown
файлам. Бэкенд на Spring Boot отслеживает директории через `WatchService`,
поэтому изменения появляются в результатах поиска почти мгновенно, без
ручной переиндексации.

## Задачи

- Задокументировать эндпоинт скачивания файлов для фронтенд-команды.
- Провести нагрузочное тестирование индексации на директории со 100 000 файлов.
