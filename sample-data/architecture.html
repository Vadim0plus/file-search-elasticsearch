Архитектура сервиса поиска файлов

Сервис состоит из трёх компонентов: backend на Spring Boot, кластер Elasticsearch и фронтенд на React. Backend отслеживает файловую систему через WatchService, извлекает текст из документов с помощью Apache Tika и индексирует результат в Elasticsearch для полнотекстового поиска.

  • Индексация: обход директории и извлечение содержимого
  • Поиск: multi_match запрос с подсветкой совпадений
  • Просмотр: превью и скачивание файлов по защищённой ссылке
